# Benchmarks

Reference solutions for the three validation tests described in the
[Testing Networks](../docs/user-guide/testing-networks/index.md) documentation.
Each file is plain whitespace-separated text: a comment block stating how it was
produced and under which conditions, one comment line naming the columns, then
the data.

| File                          | Network   | What it fixes                                                   |
| ----------------------------- | --------- | --------------------------------------------------------------- |
| `cie_h/cie_h_T1.5e4.txt`      | `cie_h`   | Collisional ionization equilibrium at `T = 1.5e4 K`              |
| `h2form/h2form_n6e7.txt`      | `h2form`  | Second-order decay of atomic hydrogen, `n_H0 = 6e7 cm^-3`        |
| `GOW/equilibrium_chi0.1.txt`  | `GOW`     | Thermal and chemical equilibrium versus density, `chi = 0.1`     |
| `GOW/equilibrium_chi1.txt`    | `GOW`     | Same, `chi = 1`                                                  |
| `GOW/equilibrium_chi10.txt`   | `GOW`     | Same, `chi = 10`                                                 |

The three GOW tables share one density grid (95 points, 10 → 981.28 cm^-3,
spaced by a factor 1.05), so they can be compared row by row.

## Provenance

`cie_h` and `h2form` were integrated with the JAFF-generated right-hand side
(`jaffgen --template python_solve_ivp`) driven by SciPy's LSODA at
`rtol = 1e-12`, `atol = 1e-30`, then checked against their closed-form
solutions before being written out. The deviation from analytic is quoted in
each file's header; it sets the accuracy floor of the reference, so comparisons
below that level are not meaningful.

Regenerate both with:

```bash
python scripts/make_benchmark_data.py
```

The `GOW` tables come from Munan Gong's PDR code using the parameters of
[Gong, Ostriker & Wolfire (2017)](https://doi.org/10.3847/1538-4357/aa7561),
one per FUV field strength. They are external reference data and are not
regenerated by any script in this repository.

## Figures

The figures in the documentation are rendered from these files with:

```bash
python scripts/make_benchmark_figures.py
```

which needs the `dev` extra (plotly + kaleido) and, for PNG export, a Chrome
binary — installed once with `plotly_get_chrome`.
